# HR Workforce Analysis

A comprehensive **HR Workforce Analysis** project exploring employee attrition, performance trends, departmental metrics, and workforce demographics. The project combines **Excel, SQL, Power BI, and Tableau** to deliver data-driven insights and interactive dashboards that support strategic HR decision-making and employee retention planning.

## 📌 Project Overview

This project analyzes HR workforce data to uncover patterns in employee attrition, satisfaction, performance, and compensation across departments. The goal is to help HR teams and management identify at-risk employee segments and make informed, data-backed decisions to improve retention and workforce planning.

## 🎯 Objectives

- Analyze employee attrition rate and identify key contributing factors
- Explore departmental and demographic trends in the workforce
- Evaluate performance, satisfaction, and compensation metrics
- Build interactive dashboards for HR stakeholders
- Provide actionable recommendations to reduce turnover

| Category | Tools |

## 📊 Key Analysis Areas

- Employee attrition rate by department, gender, and age group
- Salary and compensation distribution analysis
- Employee satisfaction and performance correlation
- Tenure and promotion trend analysis
- Department-wise workforce headcount and diversity metrics

## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/faizanjutt473/HR-Workforce-Analysis.git
   ```
2. Install Python dependencies (if using the data-processing scripts):
   ```bash
   pip install -r requirements.txt
   ```
3. Explore the `sql/` folder for database queries used in data preparation
4. Open the `excel/` workbook for spreadsheet-based analysis
5. Open the `.pbix` file in **Power BI Desktop** or the `.twbx` file in **Tableau** to view interactive dashboards
